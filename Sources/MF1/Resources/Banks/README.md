# Factory banks

The four DX7 32-voice banks of the FM-1 factory set (presets 1–128), as recovered by
[KingParamount/fm1-factory-presets](https://github.com/KingParamount/fm1-factory-presets)
from M-VAVE's preset restore tool (the V13/V14-era set; V15 may differ).

The capture and packaging are CC0 1.0. The voice data itself comes from Yamaha DX7
cartridges and community banks as selected by M-VAVE, and its rights are unclear.
Check before redistributing the app with these files.
